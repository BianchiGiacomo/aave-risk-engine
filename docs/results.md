# Results Walkthrough

This page gives a compact interpretation of the default demo output. The figures are generated by:

```bash
python -m aave_risk_engine.run_demo
```

## 1. Credit-Line Decision

![CVaR budget vs credit line](assets/cap_budget.png)

The red curve shows 99% CVaR bad debt as the borrow cap / Spoke credit line increases. The green horizontal line is the risk budget.

Interpretation:

- Below the crossing, the Spoke is inside the chosen tail-loss budget.
- Above the crossing, the credit line creates more tail bad debt than the budget allows.
- The vertical marker is the recommended max-safe cap for this model configuration.

The curve bends upward because larger liquidation queues create worse dollar execution shortfall and more stalled-liquidation risk.

## 2. Liquidation Capacity

![Liquidation slippage curve](assets/slippage_curve.png)

The slippage curve maps liquidation notional to execution shortfall. The horizontal line is liquidator break-even:

```text
bonus / (1 + bonus)
```

Interpretation:

- If slippage is below break-even, liquidators can repay debt and absorb execution cost.
- If slippage is above break-even, liquidation incentives fail.
- In the stalled case, the protocol is marked to delayed executable collateral recovery.

This is the key bridge between market liquidity and lending-protocol bad debt.

## 3. Bad-Debt Tail

![Bad debt distribution](assets/loss_distribution.png)

Most simulated scenarios do not create bad debt. The model focuses on the bad-debt tail because a lending protocol is capitalized against stress losses, not average conditions.

CVaR answers:

```text
What is the average loss in the worst 1% of scenarios?
```

That is more informative than VaR alone because it measures severity beyond the threshold.

## 4. Hub-Spoke Allocation

The Hub demo extends the same logic to multiple Spokes sharing one Hub balance:

```bash
python -m aave_risk_engine.run_hub_demo
```

The allocator assigns credit to the Spoke with the lowest marginal Hub-CVaR per dollar until the Hub balance or Hub CVaR budget binds. Lower-correlation Spokes can receive credit even when they are risky standalone, because they diversify the Hub tail.

Useful demo interaction in the dashboard:

- Open the Hub allocation tab.
- Lower `LONGTAIL`'s `rho`.
- Re-run allocation.

Expected result: `LONGTAIL` receives more credit and the diversification gain increases.
